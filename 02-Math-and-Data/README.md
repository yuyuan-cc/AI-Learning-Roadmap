# 02-Math-and-Data

## 学习目标

建立 AI 所需的数学基础，并学习使用数据分析思维解决真实问题。

## 学习内容

### 1. 线性代数基础
- 向量与矩阵
- 矩阵乘法
- 行列式与特征值
- 线性变换基础

### 2. 概率与统计基础
- 概率分布
- 条件概率
- 均值、方差、标准差
- 相关性与回归
- 假设检验基础

### 3. 微积分基础
- 导数
- 梯度
- 极值与最优化
- 凸函数与损失函数

### 4. 数据分析基础
- EDA（探索性数据分析）
- 缺失值处理
- 数据类型转换
- 分组、聚合、合并
- 数据可视化

## 关键工具

- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`

## 推荐资源

- 3Blue1Brown（线性代数）
- Khan Academy（数学）
- StatQuest（统计）
- MIT / Stanford 开源课件

## 实战项目

- 电商销售数据分析
- 房价数据探索
- 学生成绩分析
- 用户行为分析

## 学习建议

- 不必追求数学证明细节，但要理解直觉
- 学会用代码观察数据分布和相关性
- 重点理解：为什么模型会优化、为什么误差会减少
