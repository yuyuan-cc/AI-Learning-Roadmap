# 02-Math-and-Data

## 学习目标

建立 AI 所需的数学基础，并掌握数据分析思维。

## 核心内容

### 1. 线性代数
- 向量、矩阵
- 矩阵乘法
- 特征值和特征向量
- 线性空间基础

### 2. 概率与统计
- 概率分布
- 条件概率
- 均值、方差、标准差
- 相关性与相关系数
- 假设检验基础

### 3. 微积分基础
- 导数与梯度
- 极值与最优化
- 损失函数与最小值

### 4. 数据分析
- EDA（探索性数据分析）
- 缺失值处理
- 数据分组与聚合
- 数据可视化

## 关键工具

- Pandas
- Numpy
- Matplotlib
- Seaborn

## 推荐资源

- 3Blue1Brown（线性代数）
- Khan Academy（数学）

## 实战项目

- 电商销售分析
- 学生成绩分析
- 房价数据探索
- 用户行为分析
