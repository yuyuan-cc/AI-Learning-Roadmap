# 02-Math-and-Data

## 学习目标

建立 AI 所需的数学基础，并掌握数据分析思维。

## 核心内容
- 线性代数
- 概率与统计
- 微积分基础
- EDA 与数据清洗
- 数据可视化

## 学习任务

### Week 1
- [ ] 理解向量和矩阵
- [ ] 完成矩阵运算练习
- [ ] 用 NumPy 实现基本运算

### Week 2
- [ ] 理解概率分布与相关性
- [ ] 完成 10 道统计题
- [ ] 用数据验证概率理论

### Week 3
- [ ] 理解导数与梯度
- [ ] 学会实施梯度下降
- [ ] 完成一份基础数学笔记

### Week 4
- [ ] 学会 Pandas 数据清洗
- [ ] 完成 EDA 报告
- [ ] 生成可视化图表
