# 08-Interview

## 学习目标

为 AI / 数据 / 机器学习岗位做好简历、项目和面试准备。

## 面试重点

### 1. Python 和算法基础
- 数据结构
- 时间复杂度
- 编程能力

### 2. 机器学习基础
- 回归 / 分类 / 聚类
- 模型评估指标
- 过拟合与欠拟合

### 3. 深度学习基础
- 神经网络结构
- 卷积与注意力机制
- 训练与优化

### 4. LLM / NLP 基础
- Prompt Engineering
- RAG
- Embedding / 向量检索

### 5. 工程能力
- Git
- API 设计
- 部署经验
- 工程代码规范

## 简历建议

- 只突出最有价值的项目
- 用数字衡量成果
- 展示实际问题和解决思路
- 突出可交付能力

## 常见面试问题

- 什么是过拟合？如何解决？
- 什么是梯度下降？
- 逻辑回归和线性回归的区别是什么？
- 什么是 Transformer？
- 什么是 RAG？
- 你做过哪些 AI 项目？结果如何？

## 最终建议

不要只看视频，要持续输出实战项目；真正能找到工作的关键，是“你能做什么”和“你能产出什么”。
