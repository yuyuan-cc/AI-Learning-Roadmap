# 08-Interview

## 学习目标

为 AI / 数据 / 机器学习岗位准备简历、项目展示和面试能力。

## 面试重点

### 1. Python / 编程基础
- 语法基础
- 数据结构
- 时间复杂度
- 模块与代码组织

### 2. 机器学习基础
- 线性回归、逻辑回归
- 过拟合与欠拟合
- 模型评估指标
- 特征工程

### 3. 深度学习基础
- 神经网络结构
- 卷积与注意力机制
- 训练过程与优化
- 迁移学习思路

### 4. NLP / LLM 基础
- Prompt Engineering
- 文本向量表示
- Attention 与 Transformer
- RAG 与 Embedding

### 5. 工程与岗位能力
- Git / GitHub
- API 开发
- Docker 部署
- 数据处理与业务理解

## 简历建议

- 只突出最有价值的 2-3 个项目
- 用数字说明成果
- 重点展示“问题 → 方案 → 结果”
- 强调工程能力和业务价值

## 面试常见问题

- 什么是过拟合？如何避免？
- 什么是梯度下降？
- 线性回归和逻辑回归有什么区别？
- 为什么 Transformer 比传统 RNN 更适合文本？
- 什么是 RAG？
- 你做过哪些 AI 项目？为什么选这个方案？

## 最后建议

求职不是“只有一个模型就能赢”，而是你能表达清楚：

- 你知道问题是什么
- 你知道为什么用这个方法
- 你知道怎么实现和优化
- 你知道怎么部署和交付

这是 AI 工程师和普通学员最大的差别。
