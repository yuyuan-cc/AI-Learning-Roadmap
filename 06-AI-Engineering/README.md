# 06-AI-Engineering

## 学习目标

将模型能力变成可交付的 AI 应用，具备工程化部署和交付能力。

## 核心内容

### 1. 编程与工程基础
- Git 与 GitHub
- Linux 基础
- Shell 脚本
- 代码规范和目录设计

### 2. 后端与接口
- FastAPI / Flask
- HTTP / REST API
- JSON 数据处理
- 接口参数验证

### 3. 部署与运行
- Docker
- Nginx
- 服务器环境配置
- 模型服务化
- 线上部署流程

### 4. 数据工程基础
- SQL / PostgreSQL / MySQL
- Redis
- 日志管理
- 异步任务

### 5. AI 工程中常见问题
- 模型加载耗时
- 接口超时
- 提示词稳定性
- 批量推理与缓存
- 多模型切换逻辑

## 推荐工具

- FastAPI
- Docker
- PostgreSQL
- Redis
- MLflow
- Weights & Biases

## 实战项目

- 房价预测 API
- 文本分类服务
- 聊天机器人后端
- 知识库问答 Web 服务

## 学习建议

- 先会把模型封装成接口，再考虑部署上线
- 工程能力是“让模型真正可用”的关键
