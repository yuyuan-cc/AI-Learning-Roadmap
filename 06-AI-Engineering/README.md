# 06-AI-Engineering

## 学习目标

把模型能力转化为工程交付能力，具备 AI 工程师的开发能力。

## 核心内容

### 1. 编程与工程基础
- Git 与 GitHub
- Linux 基础
- Python 工程化代码规范
- 接口设计

### 2. Web 后端和部署
- FastAPI / Flask
- HTTP / REST API
- Docker
- Nginx
- 云部署

### 3. 模型服务化
- 模型加载
- API 输出封装
- 版本管理
- 日志与监控

### 4. 数据与工程链路
- 数据存储
- SQL / PostgreSQL / MySQL
- Redis
- 异步任务
- 整体部署架构

## 推荐工具

- FastAPI
- Docker
- PostgreSQL
- Redis
- MLflow
- Weights & Biases

## 实战方向

- 模型 API 服务
- 智能问答系统上线
- 业务集成与前后端联动
- AI 产品原型部署
