# 03-Machine-Learning

## 学习目标

掌握机器学习的基本原理、经典算法和模型评估方法。

## 核心内容

### 1. 监督学习
- 线性回归
- 逻辑回归
- 决策树
- 随机森林
- SVM
- KNN

### 2. 无监督学习
- K-Means
- 层次聚类
- 主成分分析（PCA）

### 3. 模型评估
- 训练集 / 验证集 / 测试集
- 交叉验证
- 精确率、召回率、F1
- AUC / ROC
- MAE / MSE / RMSE

### 4. 关键概念
- 过拟合与欠拟合
- 偏差与方差
- 梯度下降
- 特征工程

## 推荐工具

- XGBoost
- LightGBM

- Andrew Ng 机器学习课程
- Hands-On Machine Learning
- Kaggle Courses
- scikit-learn 官方文档

## 实战项目

- 信用卡欺诈检测
- 用户流失预测
- 电商销量预测
