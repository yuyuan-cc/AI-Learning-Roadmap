# 03-Machine-Learning

## 学习目标

掌握经典机器学习算法、评估方法和实际建模流程。

## 核心内容

### 1. 监督学习
- 线性回归
- 逻辑回归
- 决策树
- 随机森林
- SVM
- KNN

### 2. 无监督学习
- K-Means
- 层次聚类
- PCA（主成分分析）

### 3. 模型评估
- 训练集 / 验证集 / 测试集
- 交叉验证
- Accuracy / Precision / Recall / F1
- AUC / ROC
- MSE / RMSE / MAE

### 4. 关键概念
- 过拟合与欠拟合
- 偏差与方差
- 特征工程
- 梯度下降

## 工具栈

- `scikit-learn`
- `XGBoost`
- `LightGBM`

## 推荐课程

- Andrew Ng 机器学习专项课程
- Hands-On Machine Learning
- Kaggle 课程
- scikit-learn 官方文档

## 实战项目建议

- 房价预测
- 用户流失预测
- 信用卡欺诈检测
- 电商销量预测

## 学习建议

- 先理解一个算法的思想，再用代码实现
- 训练时重点关注评估指标，而不是单看准确率
- 公式要知道，用代码要会写
