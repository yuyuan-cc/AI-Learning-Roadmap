# AI-Learning-Roadmap

这是一个面向零基础学习者的 AI 学习路线仓库，帮助你从 Python 基础、数据分析、机器学习、深度学习，到 NLP / LLM 和 AI 工程化，最终成长为 AI 工程师。

## 学习目标

- Python 编程基础
- 数学与数据分析基础
- 机器学习基础
- 深度学习与 PyTorch
- NLP / LLM / 大模型应用
- AI 工程化与部署
- 项目实战与求职能力

## 学习路线

Python → 数学基础 → 数据分析 → 机器学习 → 深度学习 → NLP/LLM → AI 工程 → 项目实战 → 面试求职

## 使用方式

- 按目录顺序学习
- 每个阶段完成对应实战任务
- 每周总结一次学习成果
- 保持 GitHub 提交记录
