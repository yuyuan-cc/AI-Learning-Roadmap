# 04-Deep-Learning

## 学习目标

掌握深度学习的基本原理、训练流程及常见网络结构，并熟悉 PyTorch。

## 核心内容

### 1. 神经网络基础
- 神经元与激活函数
- 前向传播
- 反向传播
- 损失函数
- 优化器

### 2. 训练与调参
- Batch、Epoch、Learning Rate
- 训练 / 验证 / 测试
- 过拟合和欠拟合
- 正则化与 Dropout

### 3. 经典网络结构
- CNN（卷积神经网络）
- RNN / LSTM / GRU
- Transformer 基础
- Attention 机制

### 4. 框架与工具
- PyTorch
- TensorFlow（可选）

## 推荐课程

- PyTorch 官方教程
- 李沐深度学习课程
- Dive into Deep Learning
- Deep Learning Specialization

## 实战项目

- 手写数字识别
- CIFAR-10 图像分类
- 图像风格分类
- 文本情感分析

## 学习建议

- 先理解反向传播和梯度更新
- 再去看 CNN、RNN、Transformer 的思路
- 不要只看概念，要自己跑数据、训练模型
