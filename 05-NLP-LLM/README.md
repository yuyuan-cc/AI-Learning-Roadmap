# 05-NLP-LLM

## 学习目标

掌握自然语言处理与大模型应用的基础方法，并理解 Prompt / Embedding / RAG 的关键概念。

## 核心内容
- 文本预处理
- 词向量
- 语言模型
- Transformer
- Attention
- Prompt Engineering
- Embedding
- RAG
- Hugging Face
