# 05-NLP-LLM

## 学习目标

掌握自然语言处理、文本建模和大模型应用能力。

## 核心内容

### 1. NLP 基础
- 文本预处理
- 词袋模型
- 词向量
- 语言模型基础

### 2. 经典 NLP 任务
- 文本分类
- 情感分析
- 命名实体识别（NER）
- 摘要生成
- 问答系统

### 3. 大模型基础
- Transformer 结构
- Attention
- Prompt Engineering
- RAG（检索增强生成）
- Embedding 与向量数据库

### 4. 常用工具
- Hugging Face Transformers
- Sentence Transformers
- LangChain
- LlamaIndex
- OpenAI / Qwen / DeepSeek / Llama 等模型

## 推荐课程

- Hugging Face Course
- Stanford CS224N
- LangChain 官方文档
- LLM 相关技术博客与论文

## 项目建议

- 智能客服助手
- 文档问答系统
- 论文总结工具
- 资讯摘要机器人
- 知识库问答助手
