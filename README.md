# AI-Learning-Roadmap

零基础到 AI 工程师的完整学习路线 | Python + 机器学习 + 深度学习 | 包含课程、项目、资料

> 适合对象：零基础学习者、转行者、想进入 AI / 数据科学 / 大模型岗位的人
>
> 目标：从 Python 基础到机器学习、深度学习、NLP / LLM、大模型应用，再到 AI 工程师能力闭环

## 1. 学习路线总览

AI 学习不是“一次看完一门课就能做事”，而是分阶段建立能力：

1. Python 编程基础
2. 数学与数据分析基础
3. 机器学习基础
4. 深度学习与 PyTorch
5. NLP / LLM / 大模型应用
6. AI 工程化与部署
7. 项目实战与求职准备

路线建议：

Python → 数学基础 → 数据分析 → 机器学习 → 深度学习 → NLP/LLM → 工程化部署 → 项目实战 → 面试求职

---

## 2. 学习目标分层

### 2.1 入门阶段（0-2 个月）
- 掌握 Python 基础语法
- 熟悉 NumPy、Pandas、Matplotlib
- 理解数据清洗与可视化
- 能完成简单数据分析项目

### 2.2 基础算法阶段（2-4 个月）
- 掌握线性代数、概率统计、微积分基础
- 理解回归、分类、聚类等机器学习算法
- 熟练 scikit-learn

### 2.3 深度学习阶段（4-7 个月）
- 掌握神经网络基础
- 学会 PyTorch / TensorFlow
- 理解 CNN、RNN、Transformer

### 2.4 大模型与 AI 应用阶段（7-10 个月）
- 理解 NLP、Prompt Engineering、RAG
- 使用 Hugging Face、OpenAI / Qwen / DeepSeek 等模型
- 能做 Chatbot、问答、摘要、智能助手

### 2.5 AI 工程师阶段（10-12 个月）
- 能部署模型 API
- 会 Git、Linux、Docker、FastAPI
- 能做真实可交付的 AI 产品原型

## 4. 推荐学习时间安排

### 方案 A：3 个月快速入门
- 第 1-4 周：Python + 数据分析
- 第 5-8 周：数学 + 机器学习
- 第 9-12 周：深度学习 + 项目

### 方案 B：6 个月系统学习
- 1-2 月：Python + 数学
- 3-4 月：数据分析 + 机器学习
- 5-6 月：深度学习 + NLP + 项目

### 方案 C：12 个月升级到 AI 工程师
- 月 1-2：Python / 数据分析
- 月 3-4：机器学习
- 月 5-6：深度学习
- 月 7-8：NLP / LLM
- 月 9-10：工程化部署
- 月 11-12：项目实战 + 面试准备

---

## 5. 学习建议

- 先理解概念，再写代码
- 先做小项目，再做复杂项目
- 每周至少完成一个模块任务
- 每月做一次复盘和总结
- 不要只看教程，要输出作品

---

## 6. 最重要的原则

AI 学习真正关键的是：

1. 夯实基础
2. 持续练习
3. 做项目
4. 反复迭代
5. 形成工程化思维
