# AI-Learning-Roadmap

零基础到 AI 工程师的完整学习路线 | Python + 机器学习 + 深度学习 + LLM + AI 工程化 | 包含课程、资料、项目、交付实践

> 适合对象：零基础学习者、转行者、想进入 AI / 数据科学 / 大模型岗位的人
> 目标：从 Python 基础，到数学与数据分析，再到机器学习、深度学习、NLP / LLM、AI 工程化，最终形成能落地的 AI 实战能力。

## 1. 这份路线为什么值得学

AI 不是“只会一个模型就够了”，而是一个完整的工程能力链：

- 数据处理：清洗、分析、可视化
- 模型构建：传统机器学习 / 深度学习
- 大模型应用：Prompt、RAG、Embedding、Agent
- 工程部署：API、服务、Docker、云部署
- 项目落地：商业问题转化、数据闭环、交付能力

你真正需要的是：基础 + 项目 + 工程化 + 交付实现。不是只看教程。

## 2. 学习路线总览

### 路线图

Python → 数学基础 → 数据分析 → 机器学习 → 深度学习 → NLP / LLM → AI 工程化 → 项目实战 → 项目交付

### 目标分层

#### 第一层：入门基础（0-2 个月）
- Python 语法与工程基础
- 数据类型、流程控制、函数、类
- 文件处理、异常处理、模块管理
- NumPy / Pandas / Matplotlib / Jupyter

#### 第二层：数学与数据思维（2-4 个月）
- 线性代数
- 概率统计
- 微积分基础
- 数据清洗、EDA、可视化

#### 第三层：机器学习（2-4 个月）
- 回归、分类、聚类
- 逻辑回归、决策树、随机森林、SVM、KNN
- 模型评估、交叉验证、特征工程
- scikit-learn

#### 第四层：深度学习（3-5 个月）
- 神经网络基础
- 激活函数、损失函数、优化器
- CNN、RNN、LSTM、Transformer
- PyTorch

#### 第五层：NLP / LLM（2-4 个月）
- 文本预处理、词向量、语言模型
- Transformer、Attention、Prompt Engineering
- RAG、Embedding、向量数据库
- Hugging Face、LangChain、OpenAI / Qwen / DeepSeek

#### 第六层：AI 工程化（1-2 个月）
- Git / GitHub
- Linux / Shell
- FastAPI / Flask
- Docker / Nginx
- 云部署 / 模型服务化

#### 第七层：项目执行与交付（持续积累）
- 项目需求分析
- 数据准备与验证
- 模型开发与迭代
- API 服务化
- 部署、监控、持续优化
- 完整交付文档

## 5. 学习建议（非常重要）

### 1）不要只看视频
- 看 10 小时教程，不如写 1 小时代码
- 需要边学边做题、边写脚本、边做实验

### 2）先理解概念，再做项目
- 不要陷入“概念看懂了，但实际上不会写”的状态
- 每完成一个模块，都要有一个最小可执行项目

### 3）项目比知识更重要
- 最终的评价往往看项目和成果，而不是课程看了多少
- 作品集要能展示：思路、数据、模型、结果、部署

### 4）工程化能力决定上限
- 会训练模型不等于会做 AI 工程师
- 需要具备 API、部署、监控、迭代能力

## 8. 项目执行与交付

### 项目执行的关键步骤
- 需求分析：确认问题和目标
- 数据准备：清洗、验证、结构化
- 模型选择：基线模型与对比实验
- 评估优化：看准确率、召回率、AUC、成本
- 服务化：封装 API、部署上线
- 监控优化：日志、监控、反馈修正
- 文档交付：README、架构图、部署步骤

### 项目交付重点
- 让项目在真实场景中可用，而不是只停留在 notebook
- 用项目说明让别人知道：问题是什么、怎么做、为什么这样做、效果如何
- 项目必须具备：可运行、可解释、可迭代

## 10. 最后建议

最有效的学习方式不是“堆知识”，而是：

1. 学一点
2. 做一点
3. 总结一点
4. 输出一点
5. 迭代一点

坚持下去，半年到一年，你会从“看懂 AI”变成“能做 AI”。
