# AI-Learning-Roadmap

## 学习路线总览

### 1. Python 基础
- Python 语法
- 函数、模块、类
- 数据处理库：NumPy / Pandas
- 数据可视化：Matplotlib / Seaborn

### 2. 数学与数据分析
- 线性代数
- 概率与统计
- 微积分基础
- EDA 与数据清洗

### 3. 机器学习
- 线性回归
- 逻辑回归
- 决策树
- 随机森林
- SVM / KNN
- 模型评估与交叉验证

### 4. 深度学习
- 神经网络基础
- CNN / RNN / LSTM / Transformer
- PyTorch 学习
- 模型训练与调参

### 5. NLP / LLM
- 文本处理
- 词向量与 Embedding
- Transformer
- LLM 应用
- Prompt Engineering
- RAG

### 6. AI 工程化
- Git / GitHub
- Linux / Shell
- FastAPI / Flask
- Docker
- 模型部署
- 监控与日志

### 7. 项目实战
- 房价预测
- 用户流失分析
- 图像分类
- NLP 问答系统
- RAG 智能助手

### 8. 项目执行与交付
- 需求分析
- 数据准备
- 模型开发
- 服务化部署
- 监控与迭代
- 项目交付文档

## 学习路径建议

### 方案 A：3 个月快速入门
- Python + 数据分析
- 机器学习
- 深度学习项目

### 方案 B：6 个月系统学习
- Python + 数学
- 机器学习
- 深度学习
- NLP / LLM
- 实战项目

### 方案 C：12 个月升级到 AI 工程师
- Python / 数据分析
- 传统机器学习
- 深度学习
- LLM 应用
- 工程部署
- 项目交付

---

## 学习方法

1. 先看基础概念，再写代码
2. 每完成一个阶段做一个小项目
3. 每周做总结与复盘
4. 不只学模型，还要理解工程流程
5. 最终目标是“能做出可运行的 AI 产品”

## 结语

AI 学习不是“看完课程就会”，而是“边学边做、边修正、边迭代”。

如果你坚持做项目、理解技术栈、能完成工程化落地，那么你会逐渐从学员成长为 AI 工程师。
