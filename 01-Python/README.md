# 01-Python

## 学习目标

掌握 Python 编程基础，具备数据处理与脚本开发能力。

## 核心内容
- Python 基础语法
- 函数与模块
- 文件读写
- 异常处理
- 面向对象编程
- NumPy / Pandas / Matplotlib

## 学习任务

### Week 1
- [ ] 学会变量、数据类型、条件判断
- [ ] 完成 20 道基础题
- [ ] 实现一个小型计算器

### Week 2
- [ ] 学会列表、字典、集合
- [ ] 使用函数封装常用逻辑
- [ ] 完成 CSV 数据读取与处理

### Week 3
- [ ] 学会异常处理
- [ ] 完成一个数据分析脚本
- [ ] 画一张图表
