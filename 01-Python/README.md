# 01-Python

## 学习目标

掌握 Python 编程基础，并具备数据处理与脚本开发能力。

## 推荐学习内容

### 1. Python 基础语法
- 变量、数据类型
- 条件语句、循环
- 函数、参数、返回值
- 列表、字典、集合、元组
- 文件读写
- 异常处理

### 2. 面向对象编程
- 类与对象
- 构造函数
- 继承与封装
- 模块与包

### 3. 常用库
- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`
- `jupyter`

### 4. 实战训练
- 处理 CSV / Excel 数据
- 自动化脚本
- 数据清洗
- 简单可视化

## 推荐课程

- 廖雪峰 Python 教程
- Python 官方文档
- Kaggle Python 课程
- Coursera / Codecademy 入门课程

## 练习建议

- 做 100 道 Python 基础题
- 完成 5 个小脚本任务
- 用 Python 分析一个真实数据集

## 产出物

- 一个数据清洗脚本
- 一个数据分析小报告
- 一个可运行的 Python 自动化程序
