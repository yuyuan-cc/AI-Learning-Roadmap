# 07-Projects

## 学习目标

通过真实项目积累作品集，并形成完整的 AI 工程实践能力。

## 项目列表

### 1. 房价预测
- 背景：预测房屋价格
- 技术栈：Python / Pandas / scikit-learn
- 结果：实现回归预测
- 状态：已完成 / 待完善

### 2. 用户流失预测
- 背景：分析客户流失
- 技术栈：Python / XGBoost
- 结果：实现分类模型
- 状态：已完成 / 待完善

### 3. 文本情感分析
- 背景：识别文本情感
- 技术栈：Python / PyTorch / NLP
- 结果：实现评论分类
- 状态：已完成 / 待完善

### 4. RAG 智能助手
- 背景：基于知识库的问答
- 技术栈：Python / LangChain / Embedding
- 结果：实现智能问答
- 状态：已完成 / 待完善

## 项目模板
每个项目都建议包括：
- 项目背景
- 数据来源
- 技术栈
- 实现步骤
- 评估指标
- 结果展示
- 改进方向
