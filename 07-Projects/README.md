# 07-Projects

## 学习目标

通过真实项目训练实际开发能力，并形成作品集。

## 建议项目顺序

### 入门项目
- Python 小脚本任务
- CSV 数据清洗与分析
- 房价预测
- 用户流失预测

### 中级项目
- 图像分类系统
- 文本情感分析
- 新闻分类器
- Chatbot 原型系统

### 高级项目
- 知识库问答系统
- 智能文档助手
- RAG 智能搜索
- AI 工程化产品原型

## 项目评审指标

- 任务清晰
- 数据有效
- 方案合理
- 模型或算法可解释
- 代码规范
- README 完整
- 结果可展示

## 项目模板

每个项目建议包含：
- 背景与目标
- 数据来源
- 技术栈
- 模型设计
- 实验过程
- 结果分析
- 结论和改进方向
