# 07-Projects

## 学习目标

通过真实项目积累作品集和开发经验，形成可展示的 AI 能力。

## 推荐项目顺序

### 入门项目
- Python 数据清洗脚本
- 销售数据分析仪表盘
- 房价预测小项目
- 用户流失分析

### 中级项目
- 图像分类器
- 文本情感分析器
- 新闻分类系统
- 简单聊天机器人

### 高级项目
- 知识库问答系统
- RAG 智能搜索助手
- 文档总结与检索平台
- AI 工作流应用

## 一个好的项目应包含

- 背景与目标
- 数据来源
- 技术栈
- 数据处理流程
- 模型设计
- 评估指标
- 结果展示
- 结论与优化方向

## 项目评审标准

- 任务清晰
- 数据合理
- 逻辑完整
- 代码规范
- 可复现
- 结果有说服力
- 能讲清楚项目价值

## 项目实战建议

- 每个项目都写 README
- 每个项目都保留训练脚本和推理脚本
- 最好有可本地运行的说明
- 使用 Git 提交记录展示成长过程
